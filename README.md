## Projects

### [Football Corners Predictor](https://github.com/Git4AlexD/football-corners-predictor)
An automated daily data and machine learning pipeline covering 10 European football leagues. It collects odds and results from two data sources, trains negative-binomial regression models to forecast corner counts, and judges the forecasts by closing-line value with bootstrap confidence intervals rather than by short-run profit. It runs on a schedule in GitHub Actions and publishes its result charts every day.

`Python` `pandas` `statsmodels` `SciPy` `pytest` `GitHub Actions`

### [Spokebound](https://github.com/Git4AlexD/spokebound-chess-ai)
A chess-style strategy game, written using only the Python standard library, in which players design their own pieces. It has an alpha-beta search AI with ten difficulty levels, evaluation weights tuned by a CMA-ES optimiser I implemented from scratch, peer-to-peer online play using room codes and a relay server, and a Tkinter interface. It has an automated test suite with CI on Windows.

`Python` `game AI` `evolutionary optimisation` `networking` `Tkinter` `GitHub Actions`
